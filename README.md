# freeCodeCamp — Python Certification

Exercises and mini-projects from freeCodeCamp's Python certification, one folder per exercise.

- [`employee-profile-generator/`](employee-profile-generator/) — string concatenation, f-strings, string slicing
- [`bill-splitter/`](bill-splitter/) — running totals, arithmetic operators, `round()`
- [`movie-ticket-booking-calculator/`](movie-ticket-booking-calculator/) — conditionals, boolean logic, operator precedence
